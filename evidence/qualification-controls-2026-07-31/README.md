# Qualification controls, 2026-07-31

This bundle preserves complete synthetic model responses, finish reasons,
token usage, per-scenario results, and local resource telemetry for the final
v5 runtime diagnostics and matched Amazon Bedrock controls.

The JSON files were generated by
`scripts/publishQualificationEvidence.js`. Machine-local worktree and home
paths, host fingerprints, and battery identifiers were sanitized. Synthetic
messages, scores, timings, token counts, model/runtime/configuration digests,
and memory measurements were not changed. `index.json` maps every sanitized
file to the SHA-256 of its raw source.

The local and hosted full-suite runs are single diagnostics, not a
counterbalanced performance estimate. Their wall times are not comparable:
one measures local runtime execution on the physical host and the other
includes a local gateway to a managed service. The matching low scores show
similar scenario behavior under requested low effort and seed 42, not
bit-exact inference.

The clean coding follow-up records `source_dirty:false` and an identical
before/after source-state hash. An earlier engineering repeat produced the
same complete response SHA-256, but its controller did not yet record dirty
worktree provenance; only the clean run is promoted in this bundle.

`medium-v3-v4-evaluator-audit.json` is intentionally separate from the frozen
v3 report. It changes no response and adds no points to the original result.
