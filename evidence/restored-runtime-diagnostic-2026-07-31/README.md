# Restored runtime end-to-end diagnostic

This sanitized summary records the first protected end-to-end run after
restoring the exact checkpoint and runtime. It is a warm-host engineering
diagnostic, not a publication performance estimate or quality result.

The fixed public probe executed through direct selected-expert views with
batch 4, micro-batch 1, no prefetch, and an eight-token completion cap. The
raw local report and server log remain outside the repository because they
contain machine-specific absolute paths. Their SHA-256 digests are retained in
`summary.json`.
